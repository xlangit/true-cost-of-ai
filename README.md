# The True Cost of an AI Token

A verifiable, single-file presentation on the **physical and financial cost of generative AI** — water, electricity, e-waste, land, cooling, community backlash, the economics, China's cheap tokens, and the 2026 AI IPO wave.

Every figure is checked against primary sources (IEA, Allen Institute for AI, Lawrence Berkeley Lab, UNITAR/ITU, Uptime Institute, SEC filings, Reuters, PitchBook, Sacra…). Illustrative estimates are labeled as such; unverifiable claims were dropped.

## Read it

- **English:** [`index.html`](index.html)
- **Español:** [`index-es.html`](index-es.html)

Each version has an EN/ES toggle in the top bar. Both are self-contained single HTML files — light editorial theme, printable, with a palette/typeface switcher.

## Notes

- **Dates:** content reflects mid-June 2026. Some 2026 figures (IPOs, valuations, equity raises) come from live reporting and confidential filings, not audited statements — treat them as *reported estimates*.
- **Third-party chart:** the "AI Money Machine" visualization is by **Bloomberg News / FlowingData** and is **linked, not reproduced**, to respect their copyright.
